# 个人接单流程 workflow 推荐

## 目前 workflow

### 沟通前

我个人会同时追踪多个企业微信企业, 关注在特定群聊中的信息.
管理员/店主会不时发布接单信息, 该信息可能包含: 客户初步需求, 预算.
我个人会对认为可以接的单回复消息.

### 沟通

如果该单尚未有人沟通, 我将会在新拉的群中和客户直接沟通:

- 询问问题以确定具体需求
- 询问预算和报价
- 确认最终需求和最终报价

如果需求和报价等尚可, 我会确认接下这一单, 并准备开始工作.
得到:

- 订单编号
- 客户需求
- 该单价格-到手价格(客户支付价格的 60%)

### 开始开发

- 在 dev 文件夹中创建新的文件夹;
- 在 README (或一个其他 markdown) 中写入具体需求等内容
- 在 claude code 等协助下进行该工作

注意: 该文件夹会是 git 文件夹但是不上传到 github

### 开发过程

- 用户可能会提出新的需求
- 修改价格

### 交付

开发完成后进行交付,
我将把开发后的代码文件打包, 执行下面两步:

- 上传到云盘生成分享链接 (缺少一个在中国大陆香港地区可以快速下载的云盘方式)
- 企业微信传输
  客户满意后这单结束

### 交付后

交付后 1-2 天内我可以拿到钱, 之后,
我把文件夹放置到 Documents 中归档.
